# 📝 React Task Manager

A modern, fast, and responsive Task Management Web Application built with **React**, **Vite**, and **Tailwind CSS**. Designed with a sleek Dark Mode UI to help users manage their daily tasks efficiently with real-time filtering and status management.

---

## ✨ Features

- ➕ **Add New Task:** Quickly create tasks with titles and categories (_Dev, Backend, Study, Personal_).
- ✅ **Toggle Task Status:** Easily mark tasks as active or completed with instant visual feedback.
- 🗑️ **Delete Task:** Remove unwanted or completed tasks from the workspace.
- 🔍 **Task Filtering:** Filter tasks instantly by status (**All**, **Active**, **Completed**).
- 📊 **Dynamic Pending Counter:** Displays the number of active tasks remaining in real-time.
- 🎨 **Modern Dark Mode UI:** Clean, accessible, and responsive user interface styled with Tailwind CSS v4 and Lucide Icons.

---

## 🛠️ Tech Stack

- **Frontend Framework:** React 18+
- **Build Tool:** Vite
- **Styling:** Tailwind CSS v4 & Lucide React Icons
- **Language:** JavaScript (ES6+)

## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine.

### Prerequisites

Make sure you have **Node.js** (v18 or higher recommended) and **npm** installed on your system.

```bash
node -v
npm -v

```

### Installation & Setup

1. **Clone the Repository**

```bash
git clone [https://github.com/your-username/react-task-manager.git](https://github.com/your-username/react-task-manager.git)
cd react-task-manager

```

2. **Install Dependencies**

```bash
npm install

```

3. **Run the Development Server**

```bash
npm run dev

```

4. **Open in Browser**
   Open your browser and navigate to `http://localhost:5173/` (or the URL shown in your terminal).
